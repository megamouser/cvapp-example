Реальные коммерческие проекты

Разработка сайтов для продвижения и привлечения клиентов

Разрабатывал и дорабатывал коммерческие сайты в сотрудничестве со специалистами по веб-продвижению и SEO. Реализовывал технические требования к структуре страниц, индексации и поисковой оптимизации. Сайты использовались для продвижения продукции и привлечения лидов — заявок и обращений потенциальных покупателей в компанию.

Демонстрационный проект03

Сервис ЦФО

Демонстрационный PHP-лендинг сервиса по ремонту и обслуживанию промышленного оборудования.

Задача
Представить сервисные услуги и организовать приём обращений с сайта.
Реализация
Блоки услуг и контактов, формы с клиентской валидацией и AJAX-отправкой, сохранение заявок в SQLite и email-уведомления.
Интеграции
Webhook WhatsApp-бота: ответы на команды, информация о компании и отправка PDF-презентации. Подключена Яндекс Метрика.
Архитектура
Собственные маршрутизатор и контроллеры на PHP, шаблоны страниц и автозагрузка классов через Composer PSR-4.
Результат
Демонстрация связки лендинга, обработки заявок, базы данных и внешнего API. Исходный код опубликован на GitHub.

Архивный демонстрационный проект 2019 года. Работа внешних интеграций в текущем окружении не проверялась.

Прототип06

phpAppStart

Стартовый каркас PHP-приложения с собственной маршрутизацией и разделением контроллеров и представлений.

Задача
Подготовить минимальную основу веб-приложения для экспериментов с внешним API телефонии.
Реализация
Единая точка входа, GET- и POST-маршруты, вызов методов контроллера, HTML-шаблоны и вспомогательные методы для редиректов, URI и JSON.
Архитектура
Собственный Router, PagesController и Helper. Автозагрузка классов через Composer PSR-4, шаблон страницы на Bootstrap.
Интеграции
Подключена библиотека Zadarma API. В коде сохранены закомментированные примеры получения статистики и записей звонков; готовый интерфейс телефонии не реализован.
Результат
Демонстрационная основа для небольшого PHP-приложения. POST-обработчик представлен заглушкой.
PHPComposerPSR-4Bootstrap 4Zadarma API
